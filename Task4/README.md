# Rock-Paper-Scissors Game

A simple, user-friendly GUI Rock-Paper-Scissors game built using Python and Tkinter.  
Play against the computer, track your score, and enjoy multiple rounds with a clear interface and instant feedback.

---

## Features

- **User Input:** Choose rock, paper, or scissors via buttons.
- **Computer Selection:** Computer randomly picks its move.
- **Game Logic:** Determines winner using classic rules (rock beats scissors, scissors beat paper, paper beats rock).
- **Display Result:** Shows your choice, computer's choice, and round result (win/lose/tie).
- **Score Tracking:** Maintains user and computer scores for multiple rounds.
- **Play Again:** Click "Play" for another round, "Reset Scores" for a fresh start.
- **User Interface:** Friendly GUI with clear instructions.

---

## Installation

1. Make sure you have **Python 3.x** installed.
2. Tkinter is included with Python by default. If needed on Ubuntu/Debian, run:
sudo apt-get install python3-tk
3. Download or clone this repository.

---

## Usage

1. Save the game code as `rps_gui.py`.
2. Open a terminal and run:
python rps_gui.py
3. Play rounds by choosing your move and clicking 'Play'.
4. Reset scores at any time with the "Reset Scores" button.
