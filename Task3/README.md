# Password Generator 

This is a simple Python-based password generator application. It generates strong, randomized passwords according to the user-specified length.

---

## Features

- User specifies the desired password length.
- Generates a password combining uppercase letters, lowercase letters, numbers, and special characters.
- Displays the generated password on the screen.
- Handles invalid input gracefully.

---

## Installation

1. Make sure Python 3.x is installed on your system.
2. No additional libraries are required as it uses Python’s built-in `random` and `string` modules.

---

## Usage

1. Clone or download this repository.
2. Run the script from your terminal or command prompt:

python password_generator.py


3. When prompted, enter the desired length for the password.
4. The generated password will be displayed.

---

## Example

Enter desired password length: 12
Generated Password: 4@Gm!vZr#Tq2
