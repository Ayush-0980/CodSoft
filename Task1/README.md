# To-Do List Application

This is a simple GUI-based To-Do List application created using Python and Tkinter.  
It helps users manage and organize tasks efficiently by allowing them to add, track, and remove to-do items.

---

## Features

- Add new tasks to your to-do list
- Mark tasks as completed (appends “[Done]” to task)
- Remove tasks from the list
- User-friendly graphical interface with pop-up warnings for input errors

---

## Installation

1. Ensure you have **Python 3.x** installed.  
2. Tkinter is usually bundled with Python. If missing, install it using your OS package manager:

   - **Ubuntu/Debian:**  
     ```
     sudo apt-get install python3-tk
     ```
   - **Windows/macOS:** Comes pre-installed with Python.

---

## Usage

1. Clone or download this repository.
2. Navigate to the project folder in your terminal or command prompt.
3. Run the application with: python todo_gui.py

4. Use the GUI to add tasks, mark them as completed, or remove them.

---

## Code Overview

- The GUI is implemented with Tkinter’s `Listbox`, `Entry`, and `Button` widgets.
- The app uses simple methods to modify the task list and shows error popups for invalid operations.
- The program structure is object-oriented for maintainability and scalability.
