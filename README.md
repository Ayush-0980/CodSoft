# Simple Calculator

This is a simple GUI-based calculator built using Python and Tkinter.  
The calculator supports basic arithmetic operations: addition, subtraction, multiplication, and division.

---

## Features

- User-friendly graphical interface
- Input for two numbers
- Operation selection from addition (+), subtraction (-), multiplication (*), and division (/)
- Displays the result on the interface
- Handles invalid inputs and division by zero with error messages

---

## Installation

1. Make sure Python 3.x is installed on your system.  
2. Tkinter usually comes bundled with Python. If missing, install it:
   - On Debian/Ubuntu: `sudo apt-get install python3-tk`
   - On Windows/macOS: comes pre-installed with Python

---

## Usage

1. Clone or download this repository.  
2. Run the Python file:
3. Enter two numbers, select the operation, and click **Calculate**.  
4. The result will be displayed below the button.

---

## Code Overview

- The GUI is created using the `tkinter` library.
- `Entry` widgets are used for number inputs.
- An `OptionMenu` widget allows the user to select an operation.
- A `Button` triggers the calculation.
- Results and error messages are displayed using `Label` and popup dialogs.
