# Contact Book (Task 5)

A simple, user-friendly Contact Book application built with Python and Tkinter.

---

## Features

- **Store Contact Information:** Save name, phone, email, and address for each contact.
- **Add Contact:** Enter contact details and add to the book.
- **View Contact List:** See all your saved contacts in a list.
- **Search Contact:** Find contacts by name or phone number.
- **Update Contact:** Edit existing contacts—select a contact to autofill the input fields and update.
- **Delete Contact:** Remove unwanted contacts easily.
- **User Interface:** Clean GUI for fast, easy operation.

---

## Installation

1. Make sure you have **Python 3.x** installed.
2. Tkinter comes pre-installed. On Ubuntu/Debian, if needed:

sudo apt-get install python3-tk

3. Download or clone this repository.

---

## Usage

1. Save the Python code as `contact_book.py`.
2. Open a terminal and run:

python contact_book.py

3. Use the interface to add, edit, search, and delete contacts.
